 👋 About This Repository

This is a public record of how I'm learning cloud engineering: what I build, what breaks, how I fix it, and what I'd do differently. Every topic ends with something I actually deployed or scripted, not just notes.

My approach:

- **Build first, read second.** Theory only when a task needs it.
- **Practice daily.** Small steps, never two days off in a row.
- **Document everything**, especially mistakes and fixes.
- **Show proof, not certificates.** Projects with diagrams, READMEs and cost notes.
